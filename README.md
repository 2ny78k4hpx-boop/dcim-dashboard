# 📊 DCIM Dashboard - Monitoramento de Datacenters

Sistema web para monitoramento de infraestrutura de datacenters da Imopolis.

## 🚀 Como Usar

### Abrir o Dashboard

1. Acesse: **https://2ny78k4hpx-boop.github.io/dcim-dashboard/**
2. Visualize os dados em tempo real
3. Navegue pelas 3 abas:
   - 📊 Visão Geral (Cards)
   - 📈 Monitoramento (Gráficos)
   - 🔔 Alertas (Status)

### Editar Dados

1. Vá a: https://github.com/2ny78k4hpx-boop/dcim-dashboard/blob/main/dados.json
2. Clique no lápis ✏️
3. Mude os números que quer
4. Clique "Commit changes"
5. Recarregue o dashboard (F5)
